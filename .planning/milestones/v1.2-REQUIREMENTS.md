# Requirements: sn-api-gateway v1.2

**Defined:** 2026-02-27
**Milestone:** v1.2 Cleanup & Tech Debt
**Core Value:** The analysis pipeline must work reliably -- correct LLM invocation, proper resilience under load, and safe per-user data isolation.

## v1.2 Requirements

### Codebase Cleanup

- [x] **CLEAN-01**: Remove unreachable `Chats.get_chat()` and `Chats.delete_chat()` methods from `app/chats.py`, and their stale mock setups in `tests/conftest.py` and `tests/unit/test_services.py`
- [x] **CLEAN-02**: Fix `MainConfig.load_config` Pydantic v2 `mode='after'` validator to `return self`, resolving 2 pre-existing `test_config.py` failures

### LLM Parsing

- [x] **LLM-01**: Replace `JsonOutputParser()` with `self.llm.with_structured_output(AnalyzeResponseLLM)` for schema-guaranteed LLM responses; introduce `AnalyzeResponseLLM` intermediate Pydantic model; update test mocks accordingly

### Code Style

- [x] **STYLE-01**: Add `[tool.ruff]` config to `pyproject.toml` (rules: E, W, F, I, UP; line-length=120), run `ruff check --fix` and `ruff format`, move ruff/ty from runtime to dev dependencies

### Resilience

- [x] **RESIL-01**: Extract retries, circuit breaking, and concurrency gating from `AnalysisService._invoke()` into a unified `ResiliencePolicy` facade in `app/resilience.py`; group resilience config into `ResilienceConfig` in `app/config.py`; reduce `_invoke` to a one-liner delegation

### Health

- [x] **HEALTH-01**: Remove `ReadinessCache` class, `_probe_llm` function, and all backend connectivity checks from `app/routers/health.py`; simplify `/health/ready` to return unconditional 200/up; remove `readiness_cache_seconds` from `AppConfig` and `config.yaml`

## Out of Scope

| Feature | Reason |
|---------|--------|
| Custom JSON repair / regex extraction | Treats symptoms; `with_structured_output` eliminates root cause |
| Aggressive ruff rules (ALL, D, ANN) | Diminishing returns; E/W/F/I/UP covers hygiene |
| OutputFixingParser / retry-parse loops | Adds latency, treats symptoms |
| MainConfig dependency injection overhaul | Fix the bug, not the design |
| CI linting gate | Can be added later; v1.2 scope is local enforcement |
