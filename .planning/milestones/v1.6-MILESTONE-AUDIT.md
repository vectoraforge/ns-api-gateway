### Critical Integration Gap

**`errors.py _CODE_MAP[429]` stale after rename** — `exceptions.py` renamed `"rate_limited"` to `"quota_exceeded"` (commit `b75f440`) but `_CODE_MAP` was not updated. If a generic `StarletteHTTPException(status_code=429)` reaches `http_exception_handler`, it will attempt `ErrorResponse(code="rate_limited")` which fails Pydantic validation since `"rate_limited"` is no longer in `ErrorCode` Literal. Cascades to 500 instead of 429.

**Files needing fix:**
1. `src/nativespeaker/api/app/errors.py` line 39: `429: "rate_limited"` → `429: "quota_exceeded"`
2. `tests/unit/test_usage.py` lines 19, 91, 99: `"rate_limited"` → `"quota_exceeded"`
3. `tests/unit/test_error_contract.py` line 9: `"rate_limited"` → `"quota_exceeded"` in CONTRACT_CODES
4. `k8s/templates/backend-traffic-policy.yaml` line 53: `"rate_limited"` → `"quota_exceeded"`
