## Gaps

### GAP-1: Startup crash — config.pool_size (RESIL-01)

**Severity:** Critical — blocks production startup
**File:** `app/main.py` line 37
**Code:** `init_engine(config.db.url, config.pool_size)`
**Problem:** `AppConfig` has no `pool_size` field. Phase 8 restructured config but left a stale reference. The DB connection pool size lives at `config.db.pool_size` (from `DatabaseConfig`).
**Impact:** `AttributeError` at startup. No API routes are reachable. POST `/prompts/analyze`, POST `/chats/{id}/messages`, and DELETE `/chats/{id}` all fail.
**Why not caught:** Unit/integration tests bypass `lifespan()` — they construct `FastAPI()` directly in fixtures.
**Fix:** Change `config.pool_size` to `config.db.pool_size` on main.py line 37.

### GAP-2: Ruff compliance regression (STYLE-01)

**Severity:** Moderate — violates zero-violation baseline from Phase 7
**Files:** `app/resilience.py`, `tests/unit/test_services.py`, `tests/integration/conftest.py`
**Problem:** Phase 8 introduced 3 I001 (import sort) violations and 2 format violations. `ruff check .` exits non-zero; `ruff format --check .` would reformat 2 files.
**Fix:** `ruff check --fix . && ruff format .`

### GAP-3: Stale test mock (cosmetic, tech debt)

**Severity:** Low — dead code in test fixture
**File:** `tests/conftest.py` line 23
**Code:** `config.pool_size = 2`
**Problem:** Sets a property on MagicMock that no code reads. `AppConfig` has no `pool_size` field.
**Fix:** Remove the line.
