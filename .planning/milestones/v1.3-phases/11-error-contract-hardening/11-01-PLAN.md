```python
    "service_unavailable",
```

**2. Rewrite app/errors.py with remap table and opaque bodies:**

Add two module-level dicts after imports:

```python
from app.schema import ErrorResponse

_STATUS_REMAP: dict[int, int] = {
    405: 400,
    406: 400,
    409: 400,
    410: 404,
    413: 400,
    415: 400,
    422: 400,
    429: 503,
    502: 503,
    504: 503,
}

_CODE_MAP: dict[int, str] = {
    400: "invalid_request",
    401: "unauthorized",
    404: "not_found",
    503: "service_unavailable",
    500: "internal_error",
}
```

Then fix EVERY handler. The new body shape is `{"code": "fixed_string"}` — no `status` int, no `error` string. Use `ErrorResponse(code=X).model_dump()` for the content.


Example of the fixed `http_exception_handler` with remap:
```python
async def http_exception_handler(_: Request, exc: StarletteHTTPException) -> JSONResponse:
    status = _STATUS_REMAP.get(exc.status_code, exc.status_code)
    if status not in _CODE_MAP:
        status = 500
    return JSONResponse(
        status_code=status,
        content=ErrorResponse(code=_CODE_MAP[status]).model_dump(),
        headers=getattr(exc, "headers", None),
    )
```
