**app/config.py:**
1. Add a new `JWTConfig(BaseModel)` class (place it after `ResilienceConfig`, before `ModelConfig`):
```python
class JWTConfig(BaseModel):
    project_id: str
    jwks_url: str = Field(
        default="https://www.googleapis.com/service_accounts/v1/jwk/securetoken@system.gserviceaccount.com"
    )
    leeway_seconds: int = Field(default=30, ge=0)
    jwks_cache_ttl_seconds: float = Field(default=3600.0, gt=0)

    # Derived from project_id — not in YAML
    audience: str = ""
    issuer: str = ""

    @model_validator(mode="after")
    def derive_audience_and_issuer(self) -> "JWTConfig":
        if not self.audience:
            self.audience = self.project_id
        if not self.issuer:
            self.issuer = f"https://securetoken.google.com/{self.project_id}"
        return self
```
2. Add `jwt: JWTConfig` field to `AppConfig` — no default (required field). This means Pydantic raises `ValidationError` at startup if the `jwt:` section is missing from config.yaml, achieving the fail-fast behavior required by CONTEXT.md.

**config/config.yaml:**
Add at the end of the file:
```yaml

  project_id: native-speaker-488021
  jwks_cache_ttl_seconds: 3600
```
Only `project_id` is required. `jwks_url`, `leeway_seconds` use defaults. `audience` and `issuer` are derived by the model_validator.

**Environment variable overrides** are automatic via pydantic-settings with `env_nested_delimiter="_"`: `JWT_PROJECT_ID`, `JWT_JWKS_URL`, `JWT_LEEWAY_SECONDS`, `JWT_JWKS_CACHE_TTL_SECONDS`.
