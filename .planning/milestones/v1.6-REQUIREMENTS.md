# Requirements: ns-api-gateway

**Defined:** 2026-03-23
**Core Value:** The analysis pipeline must work reliably -- correct LLM invocation, proper resilience under load, and safe per-user data isolation.

## v1.6 Requirements

Requirements for milestone v1.6 Schema Hardening. Each maps to roadmap phases.

### Quotas

- [x] **QUOTA-01**: QuotaConfig Pydantic model maps Tier enum values to monthly quota integers
- [x] **QUOTA-02**: YAML config includes `quotas` section with tier-to-limit mapping
- [x] **QUOTA-03**: UsageDB.try_increment accepts `monthly_quota` parameter instead of JOINing plans table
- [x] **QUOTA-04**: UsageDB.get_monthly_limit removed; quota resolved from config in service/router layer
- [x] **QUOTA-05**: Plan SQLModel class and `core.plans` table eliminated

### Enums

- [x] **ENUM-01**: PostgreSQL CREATE TYPE for role, tier, subscription_provider, subscription_status in core schema
- [x] **ENUM-02**: All SQLModel enum fields use `sa_type=PG_ENUM` with `create_type=False` and `schema="core"`
- [x] **ENUM-03**: User.plan and Subscription.plan narrowed from `str` to `Tier`
- [x] **ENUM-04**: SubscriptionEvent.old_tier and new_tier narrowed from `str | None` to `Tier | None`
- [x] **ENUM-05**: UserProfileResponse.plan typed as `Tier`

### Schema

- [x] **SCHEMA-01**: Single atomic pogo-migrate migration covering CREATE TYPE, DROP DEFAULT, DROP FK, ALTER COLUMN TYPE, SET DEFAULT, DROP TABLE
- [x] **SCHEMA-02**: Message.__tablename__ corrected from "core.messages" to "messages"

### Tests

- [x] **TEST-01**: E2E conftest creates PG enum types before `create_all()` and removes plans seed data
- [x] **TEST-02**: Unit tests updated for new UsageDB.try_increment signature

### ORM Purity

- [x] **ORM-01**: `try_increment` uses `pg_insert().on_conflict_do_nothing()` + `update().where().returning()` ORM constructs instead of raw text() SQL
- [x] **ORM-02**: `get_usage` uses SQLModel `select()` instead of raw text() SQL
- [x] **ORM-03**: `reset_usage` uses SQLAlchemy core `update().where().values()` instead of raw text() SQL
- [x] **ORM-04**: No `text()` import or usage remains in `usage.py`

### Test Coverage (Phase 30)

- [x] **FIX-01**: Broken imports in test_models.py and test_services.py fixed (Issue import from models.content)
- [x] **FIX-02**: Async test markers added to subscription test class methods (7 methods)
- [x] **E2E-01**: GET /users/me has e2e tests covering all profile fields, excluded internal fields, enum values, date format
- [x] **E2E-02**: E2E error cases tested: 404 (3 endpoints), 400 (unsupported lang), 422 (missing field), 401 (no auth, invalid token)
- [x] **SEC-01**: Auth edge cases tested: empty bearer, non-bearer scheme, whitespace token, lowercase bearer, inactive user on multiple endpoints
- [x] **SEC-02**: Subscription service gaps tested: new subscription creation, missing appAccountToken, missing transaction data
- [x] **SEC-03**: Retry-After header verified on QueueFullError and CircuitOpenError responses

### Dependency Extraction (Phase 31)

- [x] **DEP-01**: `require_quota` dependency raises `QuotaExceededError` when `try_increment` returns False
- [x] **DEP-02**: `require_quota` dependency passes silently when under quota
- [x] **DEP-03**: POST /chats returns 429 when quota exhausted (via dependency, not ChatService)
- [x] **DEP-04**: POST /chats/{chat_id} returns 429 when quota exhausted (via dependency, not ChatService)
- [x] **DEP-05**: ChatService has no quotas, usage_db, or try_increment references
- [x] **DEP-06**: SubscriptionService still works with UsageDB.reset_usage (unchanged)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Migration idempotency guards (DO $$ blocks) | One-shot migration; not required for sequential versioned migrations |
| Alembic migration tooling | Project uses pogo-migrate; no migration tool change |
| Adding new plan tiers | ALTER TYPE ADD VALUE is one-way in PG; defer to future milestone if needed |
| Redis-backed circuit breaker | Single-instance deployment; unrelated to schema hardening |
| E2E subscription webhook test with real Apple JWS | Requires Apple sandbox server; unit-level coverage is sufficient |
