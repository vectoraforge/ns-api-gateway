<!-- Reference: Envoy Gateway CRD API versions and patterns from RESEARCH.md -->

Envoy Gateway v1.7.1 CRDs:
- SecurityPolicy: gateway.envoyproxy.io/v1alpha1
- BackendTrafficPolicy: gateway.envoyproxy.io/v1alpha1
- HTTPRoute: gateway.networking.k8s.io/v1

SecurityPolicy claimToHeaders field:
```yaml
claimToHeaders:
- claim: plan
  header: x-user-plan
```

BackendTrafficPolicy local rate limiting with clientSelectors:
```yaml
rateLimit:
  local:
    rules:
    - clientSelectors:
      - headers:
        - name: x-user-plan
          value: free
      limit:
        requests: 5
        unit: Minute
```

CRITICAL from research: Do NOT add a default rule (no clientSelectors) because it stacks with header-specific rules. Unknown/missing headers bypass Envoy rate limiting, which is acceptable since backend quota is authoritative.

CRITICAL from user decision: Only LLM call endpoints are rate-limited (POST /chats and POST /chats/{id}). Read endpoints (GET /users/me, GET /chats, etc.) are unrestricted. This means BackendTrafficPolicy MUST target a separate llm-routes HTTPRoute, NOT the app-routes HTTPRoute which covers /users.

responseOverride for custom 429 body:
```yaml
responseOverride:
- match:
    statusCodes:
    - type: Value
      value: 429
  response:
    contentType: application/json
    body:
      type: Inline
      inline: '{"code":"rate_limited"}'
```

- Health endpoint: GET /health/ready (used for probes)

**k8s/templates/backend-traffic-policy.yaml** -- Local rate limiting per plan tier. Targets llm-routes ONLY (not app-routes). Per user decision, only POST /chats endpoints are burst rate-limited. GET /users/me, GET /chats, etc. are unrestricted.

CRITICAL: No default rule (no clientSelectors). Only per-header rules. This avoids rule stacking where a default would also limit platinum users to 5/min.
```yaml
apiVersion: gateway.envoyproxy.io/v1alpha1
kind: BackendTrafficPolicy
metadata:
  name: {{ include "ns-api-gateway.fullname" . }}-rate-limit
  namespace: {{ .Values.namespace }}
  labels:
    {{- include "ns-api-gateway.labels" . | nindent 4 }}
spec:
  targetRefs:
  - group: gateway.networking.k8s.io
    kind: HTTPRoute
    name: {{ include "ns-api-gateway.fullname" . }}-llm-routes
  rateLimit:
    local:
      rules:
      - clientSelectors:
        - headers:
          - name: x-user-plan
            value: free
        limit:
          requests: {{ .Values.rateLimits.burst.free }}
          unit: {{ .Values.rateLimits.burst.unit }}
      - clientSelectors:
        - headers:
          - name: x-user-plan
            value: silver
        limit:
          requests: {{ .Values.rateLimits.burst.silver }}
          unit: {{ .Values.rateLimits.burst.unit }}
      - clientSelectors:
        - headers:
          - name: x-user-plan
            value: gold
        limit:
          requests: {{ .Values.rateLimits.burst.gold }}
          unit: {{ .Values.rateLimits.burst.unit }}
      - clientSelectors:
        - headers:
          - name: x-user-plan
            value: platinum
        limit:
          requests: {{ .Values.rateLimits.burst.platinum }}
          unit: {{ .Values.rateLimits.burst.unit }}
  responseOverride:
  - match:
      statusCodes:
      - type: Value
        value: 429
    response:
      contentType: application/json
      body:
        type: Inline
        inline: '{"code":"rate_limited"}'
```
