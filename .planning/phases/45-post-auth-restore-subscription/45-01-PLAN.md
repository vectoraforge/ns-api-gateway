  `Transaction.jwsRepresentation`. No iOS app exists, so nothing can produce one, and no real
  Apple artifact has ever reached this deployment (A1). The first real refusal from Apple is
  authoritative over anything this phase writes. This is a standing fact about the world, the
  same one STATE.md records for Phases 41 and 43 — not a gap this plan leaves. No checkpoint is
  raised, because D-04 is the developer's own locked decision and a checkpoint would re-ask it.
  45-05 records it in REQUIREMENTS.md.
- **The Google `stage` set.** D-11 lists "package mismatch" as a proof-rejection stage. The
  package name travels in the Play URL path, so a token that belongs to another package answers
  404 and reaches the gone-token stage. 45-02 names no separate package stage and records why.
