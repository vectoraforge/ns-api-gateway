## Decisions Made

- **Qualified names come from a parent-tracking descent, not a bare `ast.walk`.** The plan and `37.5-PATTERNS.md` both name the `ast.walk` idiom copied from `test_auth_package_shape.py`, but `ast.walk` yields nodes with no ancestry, so it cannot produce the qualified name the plan's own `<behavior>` block requires. `_named()` descends with a prefix and reaches the same node set — the nested-method control proves it.
- **The `tests` root is measured non-recursively.** `over_long(root, *, recurse=True)` takes a flag; only the `tests` key passes `recurse=False`, so `tests/unit`, `tests/e2e` and `tests/schema` are counted once each rather than twice.
- **Roots are anchored on `Path(__file__).resolve().parents[2]`**, not on the imported package. In a worktree the editable install still points at the main checkout, so a package-derived `src` path would have measured the wrong tree.
- **The baselines assert equality, not `<=`.** A sweep that lowers the debt but forgets to lower the literal fails just as loudly as one that adds a violation — that is what makes the number a record rather than a ceiling.
