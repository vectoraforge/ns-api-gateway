<objective>
Move the quota charge so that a user is never billed for a request that never reached the provider,
using an explicit admission context manager and a typed token — and without reinstating the callback
chain 37.4 deleted.

Purpose: today `charge_quota()` runs before the request reaches the gate and the breaker, so a
queue-full 503 and a circuit-open 503 both bill. 37.4 knew this and accepted it; this phase reverses it
while quota is being rebuilt anyway. It is `37.4-REVIEW.md` WR-01, still open.

Output: `ResiliencePolicy.admission()` yielding an `Admitted` token that `ainvoke` requires; the charge
a plain statement inside the admission block and outside the retry loop.
</objective>

<non_negotiables>
The charge is **never** placed inside `attempt()`, under any guard. Per A-01 it fails three ways at
once and every one of them is client-visible:

1. tenacity retries `attempt()` up to three times and the gate slot is acquired per attempt, so the
   user is **charged three times**;
2. the `except Exception` arm wraps the quota rejection into a transient or permanent LLM error,
   converting the rejection into a **503**;
3. that same arm calls `record_failure()`, so **one user's exhausted allowance counts toward opening
   the breaker for every other caller**.

`37.4-REVIEW.md` WR-01's own proposed fix is the `on_admitted` callback D-07 forbids. Adopt its
diagnosis; never its remedy. Two further seams were costed and rejected: probe-then-charge (a TOCTOU
between the probe returning and the slot actually being acquired) and charging inside `attempt()`
guarded by a one-shot flag (still inside the retry, and hidden control flow of exactly the register
four phases have been deleting).

`CircuitBreaker` and `LLMExecutionGate` stay (D-11). `_sleep_if_positive` stays (A-04) — it is the
callable tenacity's `sleep=` requires, which is D-08's own boundary carve-out, and
`test_resilience_retry.py:257` pins a real behaviour: a zero-length backoff issues no sleep at all.
Six further private helpers in this file are keeps with grounds recorded in plan `37.5-10`:
`_is_transient_error` (the transient classifier rule), `_should_retry` (tenacity's predicate) and
`_inflight_slot` (an acquire/release critical section and the sole raise site of the queue-full
rejection).
</non_negotiables>
