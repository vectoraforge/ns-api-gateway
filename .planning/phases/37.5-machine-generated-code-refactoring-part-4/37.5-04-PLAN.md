<objective>
Take the error tree's self-check out of production code and delete four exception classes that nothing
raises — without losing a single assertion and without touching the two functions that look like
self-checks and are not.

Purpose: verifying the shape of the code is a test's job. The trap is that D-09's replacement test
largely already exists (A-11): the work is rehosting the checker, and eight cases run it in a fresh
interpreter that will not find a test-tree helper without being told where to look.

Output: `errors.py` shorter by roughly 110 lines; `tests/unit/error_tree.py` holding the checker
verbatim; `ChallengeRequired`, `ChallengeRejected`, `_family` and `class_answering_status` untouched.
</objective>
