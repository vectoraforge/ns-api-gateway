**Part 2 — the AST measurement** (`:26-36`). Copy the walk idiom exactly: `ast.parse(path.read_text())`
then `ast.walk`, so a method and a nested helper both count. `ast.get_docstring(node, clean=True)` is
the docstring analogue of the `isinstance` counts.

```python
def _measure(directory: Path) -> tuple[int, int, int]:
    """Count the top-level modules, and every class and function they define at any nesting depth."""
    modules = sorted(directory.glob("*.py"))
    classes = functions = 0
    for module in modules:
        tree = ast.parse(module.read_text())
        # Walked rather than read off the module's top level, so a method or a nested helper counts.
        classes += sum(isinstance(node, ast.ClassDef) for node in ast.walk(tree))
        functions += sum(isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef))
                         for node in ast.walk(tree))
    return len(modules), classes, functions
```

Note the difference to design for: `_measure` globs one directory's top level
(`directory.glob("*.py")`). The docstring bar must recurse (`rglob`) across `src/` and `tests/`.

## Shared Patterns

### Layered call chain (D-01's whole point)
**Source:** `routers/chats.py` → `services/chats.py::ChatService` → `crud/chats.py::ChatsDB`
**Apply to:** every file this phase moves.
Router takes `Depends()` only and maps domain objects onto response models; service holds rules,
raises typed errors, owns the transaction boundary; CRUD builds statements and returns rows. The
only sanctioned CRUD-side raise is a fail-closed rejection (`ChallengesDB.verify_binding`, A-06).

### Typed rejections, never translated
**Source:** `errors.py:35-53` (`AppError`), raised throughout `services/` and `crud/`
**Apply to:** `services/auth.py`, `services/quota.py`, `crud/identities.py`
```python
class AppError(Exception):
    """Base for every failure that has a client-visible answer."""

    # A class declaring neither answers 500 `internal_error`: the fail-closed default, not a shortcut.
    status: int = 500
    code: ErrorCode = "internal_error"
    log_level: int | None = logging.WARNING
    answers_framework_status: bool = False
```
One `add_exception_handler(AppError, ...)` covers the tree via MRO, so a moved raise site needs no
handler change. **Do not regress `extra_headers()`** on `InvalidExternalJwt` / `UserNotFound`
(landed post-37.4 in `a981e4b`, `53c7f4a`) while moving code.

### One instant per request
**Source:** `dependencies.py:82-83`; `routers/auth.py:49`, `:79`
**Apply to:** `services/auth.py`, `services/quota.py`, `crud/identities.py`
`evaluated_at` is captured once at the DI accessor and threaded down as a parameter. No module below
the accessor calls `datetime.now()`. `quota.py:46-47` derives the period from it, never from a clock.

### Session ownership
**Source:** `dependencies.py:21-28` (`get_db` commits/rolls back around the handler);
`quota.py:78` (a short session from the factory for anything that must commit independently)
**Apply to:** `services/auth.py` (uses `get_db`'s session and commits explicitly at the two points
`routers/auth.py:121,171` commit today), `services/quota.py` (its own short session — C4).

### Structured logging
**Source:** `quota.py:19,29`; `routers/auth.py:35,53,146,169`
**Apply to:** `services/auth.py`, `services/quota.py`
`logger = structlog.get_logger()` at module level; event name is a fixed identifier; values come from
a closed set (`branch=`, `failure=type(x).__name__`, `challenge_row_id=`). **The challenge handle is a
secret** — `crud/challenges.py:1` records that the module holds no logger for that reason. It must not
gain one, and no moved code may log `challenge_id`.

### Package facade
**Source:** `crud/__init__.py:1-4`, `services/__init__.py:1-4`
**Apply to:** `crud/__init__.py` (+`IdentitiesDB`), `services/__init__.py` (+`AuthService`,
+`QuotaService`), `tables/__init__.py` (−4 schema names), `schemas/__init__.py` (currently empty —
decide once whether it gains a facade at all).
`__all__` first as a sorted literal, then explicit `from … import` lines. `auth/__init__.py` is the
counter-pattern and stays that way: `"""The auth package exposes nothing from its root: import from
the concrete submodule."""`
