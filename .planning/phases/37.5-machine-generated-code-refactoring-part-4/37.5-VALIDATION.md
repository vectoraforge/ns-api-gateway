## Sampling Rate

- **After every task commit:** `.venv/bin/python -m pytest -q` + the import gate.
- **After every plan wave:** the above, plus `ruff check`, `ty check`, and `pytest -m schema --collect-only`.
- **Before `/gsd:verify-work`:** full suite (`-m ""`) green against real PostgreSQL, plus the D-12
  docstring gate reporting 0.
- **Max feedback latency:** ~35 seconds.
