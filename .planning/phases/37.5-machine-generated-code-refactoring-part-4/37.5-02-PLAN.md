<objective>
The tracer. Wire one complete vertical through the restored layering — HTTP handler → `services/` →
`crud/` → `schemas/` — for the `POST /auth/create-user` path, and prove it end to end before any other
decision moves code.

Purpose: this is D-01's whole claim, and it is the largest single violation of the pattern in the
codebase. Proving the new layering on one real path first means an architectural dead end costs one
commit instead of ten. Every later plan builds on the homes this plan establishes.

`auth/create_user.py` deleted; `routers/auth.py` thinned to two handlers; `auth/` holding exactly its
three external-SDK seam files.
</objective>
