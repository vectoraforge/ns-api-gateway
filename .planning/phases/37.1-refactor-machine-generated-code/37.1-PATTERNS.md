## 3. The FastAPI Dependency Analog (D-07 / D-09)

### 3.1 House style — this is the shape the new dependency must match

**Source: `src/.../app/dependencies.py:20-42`.** Note: positional `Request`, plain `= Depends(...)`
defaults (**not** `Annotated[...]`), hanging indent aligned to the open paren, no decorators.

```python
def get_config(request: Request) -> AppConfig:
    return request.app.state.config


async def get_db(request: Request) -> AsyncGenerator[AsyncSession]:
    async with request.app.state.session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise


def get_chat_service(request: Request,
                     db: AsyncSession = Depends(get_db),
                     config: AppConfig = Depends(get_config)) -> ChatService:
```

**Source: `src/.../routers/chats.py:13` and `:33-34`** — the per-endpoint declaration style D-07's
second half must reproduce, and the `APIRouter(...)` constructor that gains `dependencies=[...]`:

```python
router = APIRouter(tags=["chats"])
...
@router.get("/chats", response_model=list[ChatResponse], summary="List chats", description="...")
async def list_chats(identity: LinkedIdentity = Depends(get_linked_identity),
                     service: ChatService = Depends(get_chat_service)):
```

**Source: `src/.../routers/health.py:4`** — the public router that gets **no** `dependencies=`:
`router = APIRouter(tags=["health"])`.

### 3.2 The seam being inverted — `dependencies.py:62-90` today

```python
def get_request_context(request: Request) -> RequestContext:
    context = getattr(request.state, REQUEST_CONTEXT_SCOPE_KEY, None)
    if not isinstance(context, RequestContext):
        raise AuthenticationError("No identity context on this request: it ran outside the barrier")
    return context


def get_linked_identity(request: Request) -> LinkedIdentity:
    identity = get_request_context(request).identity
    if not isinstance(identity, LinkedIdentity):
        raise AuthenticationError("Identity context is pre-auth on a route requiring a linked identity")
    return identity
```

All three become `async def`; the two wrappers become
`identity = (await get_request_context(request)).identity`. **`REQUEST_CONTEXT_SCOPE_KEY`
(`context.py:37`) and the `getattr(request.state, ...)` read die with the middleware** — there is no
longer a writer.

> already call out. The dependency must open `request.app.state.session_factory()` itself.

### 3.4 The one genuinely new design decision — rejection delivery

`barrier.py:167` *returns* `error_response(error_class)` rather than raising, because
`add_middleware` places it **outside** Starlette's `ExceptionMiddleware`
(`barrier.py:3-6`, `errors.py:73-75`). **A dependency runs inside it, so that whole rationale
evaporates and the dependency should raise.** But:

- `app/errors.py:66` registers `service_error_handler` for `ServiceError`.
- `errors.py:328-335` — `ServiceError.error_class` is a **class attribute**, and `log_level` too.
- `errors.py:431-438` — `AuthenticationError` → `AUTH_REQUIRED`, `log_level = logging.WARNING`.
- **There is no `ServiceError` subclass for `PREAUTH_IDENTITY_NOT_ALLOWED` (`errors.py:97`) or
  `ACCOUNT_UNAVAILABLE` (`errors.py:104`)** — the barrier reached those `ErrorClass` objects
  directly via `error_response(decision.error_class)`.

The planner must choose one: (a) one new `ServiceError` subclass carrying a per-*instance*
`error_class`, or (b) three new subclasses. Also note `AuthenticationError.log_level =
logging.WARNING` will emit a **second** log line beside `record_rejection`'s `auth_rejected` warning —
decide whether the new class sets `log_level = None`.

### 3.5 The caching contract (D-07)

`use_cache` defaults to `True` and FastAPI keys the per-request cache on the **callable object**.
Both levels must reference the *identical* function object:

```python
router = APIRouter(tags=["chats"], dependencies=[Depends(get_linked_identity)])
...
async def list_chats(identity: LinkedIdentity = Depends(get_linked_identity), ...):
```

`get_linked_identity` and `get_preauth_identity` are thin wrappers over
`Depends(get_request_context)` — that inner dependency is also cached, so the verify + resolve runs
once even across two different wrappers. **No `use_cache=False` anywhere on this path; no
`functools.wraps` wrapper at either level.**
