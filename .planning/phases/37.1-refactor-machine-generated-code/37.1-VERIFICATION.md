### Gap 1 — CR-01 wire-contract change — ACCEPTED AS OVERRIDE

**Decision:** the developer reviewed the measured scope and accepted the status-code change rather
than restoring pre-swap ordering. No code change applied.

**Measured scope** (orchestrator probe against the live app, every registered route, undecodable
body `b'{"lang": '` with explicit `content-type: application/json` and no `Authorization` header):

| Route | Result |
|---|---|
| `POST /auth/create-user` | 422 `{"code":"validation_error"}` — was 401 |
| `POST /chats` | 422 — was 401 |
| `POST /chats/{chat_id}` | 422 — was 401 |
| `GET /`, `GET /chats`, `GET /chats/{chat_id}`, `DELETE /chats/{chat_id}`, `GET /examples` | 401 `auth_required` — unchanged |
| `GET /health/ready` | 200 — intentionally public |

Only the three body-carrying POST routes are affected. Note the trigger requires an explicit JSON
content-type: without that header all nine routes still return 401, which is why an earlier probe
of this same gap failed to reproduce it.

**Why accepted:**
- The response body is a bare `{"code": "validation_error"}` — no Pydantic field names, no schema
  detail. Nothing about server state is disclosed.
- The malformed body is attacker-supplied, so the 422 tells the caller only what they already knew.
  The route's existence was already disclosed by 401-vs-404 on the same path.
- No side effects: the handler never runs, so no DB write and no quota charge.
- Residual risk is that attacker-controlled JSON is parsed before authentication — a thin DoS
  surface, mitigated by Envoy's per-IP rate limiting ahead of this service.

**Still true and still uncovered:** `tests/e2e/test_chats.py::test_the_refusal_precedes_body_validation`
and `tests/e2e/test_error_cases.py::test_a_malformed_body_is_not_disclosed` both assert
refusal-precedes-body-validation but send decodable JSON, so neither exercises the accepted path.
Their names now overstate what they prove. A future phase should either rename them or add a case
sending undecodable bytes that asserts the accepted 422.
