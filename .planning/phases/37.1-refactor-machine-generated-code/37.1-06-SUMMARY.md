## Deviations from Plan

**1. [Rule 3 — blocking] The plan's file list named two paths that no longer exist.**
`tests/e2e/test_barrier_admission.py` and `tests/e2e/test_barrier_wire_contract.py` were renamed by plan 02 to `test_admission.py` and `test_wire_contract.py`. Treated the renamed files as the ones the plan means, per the orchestrator's prior-wave briefing. Not renamed back.

**2. `tests/e2e/test_startup_assertion.py` was not renamed, and the deferred item stays deferred.**
The orchestrator allowed the rename "if your plan's prose work makes that natural". It does not: the plan's prohibition list opens with "no rename", and its own Task 1 acceptance criterion names `tests/e2e/test_startup_assertion.py` by path. A prohibition marked `status: required` outranks a tidy-up. The deferred-items entry from plan 02 remains valid and unclaimed.

**3. One cross-reference grep hit survives, deliberately.**
`tests/schema/test_inventory.py:245` reads `"updated_at is maintained by application writes, never by a trigger (D-09)"`. It is the message half of an `assert`, not prose — a string literal in the AST. Editing it would flip the AST-equality check to `CHANGED` and would violate the plan's `no assertion altered` prohibition, which carries `status: required` and outranks the grep criterion. Left as-is. A future plan that is allowed to touch assertion text should drop the `(D-09)`.

**4. The migration was not re-applied to the dev/test database.**
Task 3's action says to re-apply it; the orchestrator's briefing forbids dropping or re-applying the shared database while five sibling agents run against it. Resolved without weakening the evidence: `tests/schema/conftest.py::_schema_db_uri` already drops and creates its own `ns_schema_test` scratch database and applies `migrations/` into it through `pogo_core.util.testing.apply`, resolving `migrations/` relative to this worktree. Running `-m schema` therefore *is* a from-empty apply of the edited file, followed by the full object-inventory assertions and a pogo rollback. It passed, 115 green, with the shared `nativespeaker` database untouched.

No architectural changes. No auth gates. No packages installed.
