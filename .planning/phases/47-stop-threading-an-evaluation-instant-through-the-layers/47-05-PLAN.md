<objective>
The subscription write path stops threading an instant: the seven `SubscriptionsDB` writers read their
own clock, and `RestoreService` and `SubscriptionsService` each read once at the top of the one method
that needs it.

This plan owns the phase's one genuinely load-bearing test relocation. `services/restore.py`'s
term-open check is the only comparison a test can no longer reach once the clock moves inline, and
there is a case pinned on its exact boundary — a term ending at the very instant the request is
evaluated is **over**, because the predicate is `>` and not `>=`. That case is the guard on a paid
entitlement. It does not get deleted for convenience: the comparison is extracted into a pure helper,
`_open_term(candidates, instant)`, and the case moves onto it.

**Adopted from RESEARCH Open Questions 2, 4 and 5, as written:**
- Each crud writer reads its own clock once at the top of its method.
- `_open_term` and the re-shaped `_this_month(instant)` live in `services/restore.py`, never in
  `auth/`, so `tests/unit/test_auth_package_shape.py`'s ratchet is untouched.
- No time-freezing library is introduced. There is none in this repository today and the product
  instruction is not to over-engineer. Every relocated case uses a pure helper that takes its datetime,
  or a bracketed assertion, or stored state.

**Accepted consequence, named so a reviewer does not rediscover it.** `upsert_subscription` calls
`claim_subscription_owner` and `hold_subscription_clock`, so one upsert can now read the clock up to
three times, microseconds apart, all writing the same `updated_at` column. The final stored value is
whichever write lands last, exactly as it is today; only the microseconds differ. Build nothing to
prevent it. Where a test asserted exact equality between two such values, bracket it instead.

Purpose: criteria 1, 2 and 3 for the subscription and restore paths, with the term boundary relocated
rather than dropped.
Output: seven writers and two services with no instant threaded through them, one new pure helper, one
new unit module, and the repository's only `get_evaluated_at` override deleted.

**Reversibility:** `reversible` — signatures, one extracted helper and their call sites.

**Executor note.** `IS_WORKTREE` is **false** in this repository: GSD's detector reports true because
this repo is a submodule whose `.git` is a file, and believing it makes tracking writes vanish.
</objective>
