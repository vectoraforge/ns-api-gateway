<objective>
The tracer. Wire one full chain — dependency to router to service to service to crud to SQL — with
no instant threaded through it, and prove it end to end against the real database before any other
task in this phase runs.

The chain is the quota charge: `get_chat_service` → `ChatService` → `QuotaService.charge` →
`GrantsDB.lock_effective_grants` → `_effective_grants_statement`. It is the chain that carries the
phase's one risky decision, **D-01**, because the effective-grant predicate is the only SQL
comparison in the product that gates a paid entitlement.

**D-01 (locked by the user, 2026-09-11):** the two SQL comparisons against the current time use
`func.clock_timestamp()`, not `func.now()`. This plan applies it to the first one, the effective-grant
predicate in `crud/grants.py`. **Stated deviation from the roadmap:** roadmap criterion 3 words this
as "`now()`". PostgreSQL's `now()` is `transaction_timestamp()`, fixed at the start of the
transaction. The e2e harness (`tests/e2e/conftest.py:253-275`) holds one outer transaction open per
test and joins every app session to it with `create_savepoint`, so a grant seeded inside the test is
invisible to `now()` — measured in RESEARCH Finding 1 as 11 of 41 e2e quota tests turning red, with
`clock_timestamp()` measured green on all 41 plus 25 more. Today's `evaluated_at` is a wall-clock
read, so `clock_timestamp()` is the faithful translation and `now()` would be the behavior change.
Criterion 3 is met in spirit — the comparison is database-side — and the deviation is recorded here
and in `must_haves.truths` so the checker and the verifier see it rather than rediscover it.

Purpose: prove the architecture of the whole phase on one path first. If a database-side clock in the
entitlement predicate is wrong, this plan finds it in one commit instead of after six.
Output: the charge chain with no `evaluated_at` anywhere in it, green on the unit, e2e and schema
suites that cover it.

**Reversibility:** `reversible`. `func.clock_timestamp()` is one expression in one private statement
builder; reverting it is a one-line edit with no stored data to migrate and no published contract to
break.

**Recorded planning choices (visible, not silent):**
- Spec-less probe fallback was skipped: this phase maps no requirement IDs, so there is nothing to
  probe. `requirements: []` is deliberate, and the five roadmap success criteria are carried in
  `must_haves.truths` across the seven plans instead.
- `IS_WORKTREE` is **false** in this repository. GSD's detector reports true because this repo is a
  submodule whose `.git` is a file; believing it makes tracking writes vanish.
</objective>
