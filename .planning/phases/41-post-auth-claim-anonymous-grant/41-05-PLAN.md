1. **iOS only.** The brief scopes the Android Play Integrity branch and the web Turnstile branch into

   costs a vendor round trip. Record the mitigating fact plainly: the check is repeated inside the
   locked transaction regardless, so the gate is deferred past a cheap refusal rather than skipped.

   device bit for the same grant. Refused with the shared 403. Record the fallback this gives up — a
   registered user whose provider account already spent its grant — and that it is recorded under
   Deferred Ideas rather than lost.

   holding an active anonymous device grant answers 200 with the current entitlement. Record the two
   states that still refuse, so the amendment is not read as "repeats always succeed".

and the rule that produced it.
