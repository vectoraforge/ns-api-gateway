<objective>
Remove ReadinessCache and all backend health probes; simplify /health/ready to an unconditional 200/up endpoint.

Purpose: The current health endpoint performs expensive DB and LLM connectivity checks on every call, using a ReadinessCache with async locks and TTL. This is unnecessary -- if lifespan initialization fails, FastAPI never starts serving. The endpoint should report "up" unconditionally.

Output: Minimal health endpoint, cleaned config, passing tests.
</objective>
