<objective>
Replace fragile JsonOutputParser with LangChain's with_structured_output for schema-guaranteed LLM responses.

Purpose: Eliminate the fragile `JsonOutputParser` -> `model_validate` pipeline. OpenAI's Structured Outputs API uses constrained decoding at the token-generation level, making it physically impossible for the LLM to produce invalid JSON. This shifts validation from client-side (after generation) to server-side (during generation).

Output: Updated `app/schema.py` with `AnalyzeResponseLLM` model, refactored `app/services.py` using `with_structured_output`, and updated test mocks in `tests/unit/test_services.py`.
</objective>
