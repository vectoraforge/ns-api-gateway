<objective>
Prove the three properties only the real stack can show: that `identity_provider` comes from the
stored column and agrees with what `/auth/sync` reports, that a broken token set fails closed as an
opaque 500, and that a successful request leaves every table byte-identical.

Purpose: plan 39-01's tracer proved one happy path end to end and plan 39-03 pinned the route's shape
against doubles. Neither can show agreement across two endpoints reading the same stored column, nor
that the read really writes nothing. Those need the real database.
Output: the completed `tests/e2e/test_users_me.py`.
</objective>
