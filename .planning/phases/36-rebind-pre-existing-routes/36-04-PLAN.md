## Flagged assumption — REBIND-05 (edge probe item 6, `unclassified`, left unresolved)

The probe could not classify REBIND-05 and it is **not** auto-resolved. Three things the requirement
text leaves open, decided here as assumptions rather than derivations:

1. **"the shared predicate" is named but never defined.** This plan fixes it as: `status` is exactly
   `active`, `starts_at <= evaluated_at`, and `ends_at` is NULL or strictly greater than
   `evaluated_at`. D-03 exists so Phase 38 shares this exact predicate; if Phase 38's reading of
   `03-sync.md §42-45` differs, the difference must be resolved there, not silently reconciled.
2. **Boundary inclusivity is a choice, not a derivation.** Lower bound inclusive, upper bound
   exclusive. Chosen so a grant that ends at the instant its successor starts is effective for
   exactly one of them, never both and never neither.
3. **"never lets `remaining` go negative" does not say what an already-over-allowance row means.**
   A usage row with `monthly_used > allowance` — reachable by a tier downgrade, which no phase ships
   yet — is treated as ordinary exhaustion: clamp to zero, reject 429. It is **not** treated as a
   broken invariant, because unlike a missing usage row it does not imply a failed write.

If a reviewer disagrees with any of the three, REBIND-05 needs a decision before verification rather
than a re-plan of these tasks.
