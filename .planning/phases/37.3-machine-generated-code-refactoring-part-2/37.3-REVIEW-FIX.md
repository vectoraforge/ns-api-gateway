### WR-21: the lifespan `finally` is one unguarded sequence

**Files modified:** `src/nativespeaker/api/app/lifespan.py`
**Commit:** `e13753b`
**Applied fix:** Each cleanup step is now guarded on its own — `db_engine.dispose()`, each
`httpx.AsyncClient.aclose()`, and each `firebase_admin.delete_app()` — with a
`shutdown_step_failed` ERROR carrying a `step=` field and `exc_info=True`. The `delete_app`

review's `partial` / `iscoroutinefunction` sketch: the review states "any equivalent per-step
`try/except` is fine", and the explicit form needs no new imports and no runtime
sync/async dispatch. Per AGENTS.md, not over-engineered.
