## Scope (pre-discussion)

The ROADMAP entry was a stub ("[Urgent work - to be planned]"). The developer supplied three verbatim
directives in response to the scope question: (1) replace the auth result-enum machinery with
exceptions carrying their own response class (DRF style) in a new `auth/exceptions.py`, with one
FastAPI handler; (2) refactor the create-user provider lookup to exception style
(`VerifiedProviderIdentity` + `ProviderLookupError` hierarchy, resolution inline in `_read`, local
try/except in `_complete`); (3) apply the same conversion to `resolve_identity` and
`verify_binding`, with the binding conversion isolated from the Firebase refactor because the
precedence suite is the safety net for both.
