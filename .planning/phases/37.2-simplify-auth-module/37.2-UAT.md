### Acceptance record

**What is accepted:** `POST /auth/challenge` may be called in a loop by any caller holding a
valid token, and every call inserts a row into `core.auth_challenges` that nothing ever
deletes. No limit applies at any layer.

**Why the original rationale did not hold:**

- No HTTPRoute matches `/auth` (`k8s/templates/httproute-app.yaml` matches only `/chats`,
  `/users`, `/examples`), so no `BackendTrafficPolicy` reaches this route. Confirmed
  pre-existing — `git show 9ecebed:k8s/templates/httproute-app.yaml` shows the same three
  matches before Phase 37.2 began.
- Phase 35 D-05 removed the in-process limiter from the product entirely.
- §9's gateway contract is deferred to v2.1 per Phase 35 D-08.
- **No traffic rate limit is planned in this milestone at any layer** (developer directive,
  this UAT session). So "Envoy handles it" was not merely wrong about today — it is not a
  deferred truth either.
- Rows carry a 300s TTL but nothing reaps them. `ix_auth_challenges_expires_at`
  (`migrations/20260818_01_initial-release.sql:417`) was created for a reaper that was never
  built, so growth is monotonic rather than steady-state.

**The premises the acceptance actually rests on:**

- **Issuance is not anonymous.** `app/dependencies.py::get_request_context` requires a
  JWKS-verified Bearer token for the configured issuer before the handler runs. A caller must
  first hold a real Firebase account, and Firebase rate-limits account creation and sign-in
  itself. The pre-auth allowlist widens *which identities* may call the route, not *whether a
  verified token is required*.
- A challenge row is a few hundred bytes.
- The product is pre-launch with no users (AGENTS.md).

**Residual risk, accepted knowingly:** a single valid token can grow `core.auth_challenges`
without bound, and no expired row is ever deleted. A reaper (migration or CronJob) is the
cheapest close and should land before launch. Tracked as a deferred follow-up below rather
than as a gap, since it is an accepted risk, not a defect to fix in this phase.
