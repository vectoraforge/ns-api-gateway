<objective>
Wire `POST /auth/challenge` through every layer this phase touches — request model, router handler,
challenge store, PostgreSQL, response — for the one path that must work: an unlinked caller asks for
a `create_user` challenge and gets one, then spends it at the existing completion route.

Purpose: the endpoint split is the only client-contract change in Phase 37.2. Proving it end to end
first means every later deletion (the mode signal, the pre-check, the facade) removes code from a
system already known to work in its new shape.

Output: a live `/auth/challenge` route, two Pydantic models relocated into `models/auth.py`, and an
e2e case that walks the new route through to a created account.
</objective>

A reaper is the cheapest close and should land before launch. Accepted by the developer at UAT, 2026-08-25. |
