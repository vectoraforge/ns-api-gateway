<objective>
Collapse Firebase credential acquisition to Application Default Credentials and delete the entire
service-account configuration surface it was competing with.

Purpose: production runs on GKE where ADC is Workload Identity — strictly better than a mounted key —
and organization policy already forbids minting a service-account key at all. The second credential
path has been dead operationally for some time; this deletes the code that pretends otherwise.

Output: a one-source `build_admin_apps`, no `FirebaseConfig`, no Firebase key in `.env.example`, and
the test suite shrunk to the arm that survives.
</objective>
