<objective>
Delete the eight adapter types with no consumer anywhere, the two unconsumed methods on the one live
Protocol, and the ninety-eight-line lazy re-export facade at the root of the auth package.

Purpose: these were written phases ahead of the code that would use them, and the phases that will
actually need them (43–46) will define their interface beside its first implementation instead — the
same treatment the provider-callback category already got. The facade is machinery serving an import
convention no module follows.

Output: an `adapters.py` describing one seam, an empty package init, and the test suites that pinned
the deleted surface shrunk to what survives.
</objective>
