    REQUEST_CONTEXT_SCOPE_KEY = "ns_request_context"

    class IdentityKind(StrEnum): linked, preauth
    class ClientIpBucketKind(StrEnum): ipv4, ipv6, unresolved

    @dataclass(frozen=True, slots=True)
    class LinkedIdentity:
        kind: Literal[IdentityKind.linked]
        user: User                    # core.users row: id, active, registered_at, ...
        identity: ExternalIdentity    # core.external_identities row: id, issuer, identity_state,
                                      #   provider, provider_uid
        issuer: str
        subject: str

    @dataclass(frozen=True, slots=True)
    class PreAuthIdentity:
        kind: Literal[IdentityKind.preauth]
        issuer: str
        subject: str

    @dataclass(frozen=True, slots=True)
    class RequestContext:
        identity: LinkedIdentity | PreAuthIdentity
        route_metadata: RouteMetadata
        client_ip_bucket_kind: ClientIpBucketKind
        evaluated_at: datetime        # the ONE captured evaluation time for this request
        attempt_id: UUID              # server-generated, uuid7

src/nativespeaker/api/app/dependencies.py
    def get_request_context(request: Request) -> RequestContext        # raises when absent
    def get_linked_identity(request: Request) -> LinkedIdentity        # raises when absent or pre-auth
    def get_preauth_identity(request: Request) -> PreAuthIdentity      # raises when absent or linked

and the `core.external_identities` SQLModel table, following the enum-and-table idiom in
`models/subscriptions.py`. `IdentityProvider` has `anonymous`, `google`, `apple`;
`IdentityState` has exactly `active` and `historical`; `NativeClaimProvider` mirrors

`free_grant_consumed_at` (nullable), `created_at`, `updated_at`, `historical_at` (nullable),
with `__table_args__` carrying `{"schema": "core"}`. Do not encode the table CHECKs in Python —
the database owns them.

Create `src/nativespeaker/api/auth/context.py` with the five §1.4 symbols. `LinkedIdentity`
carries the resolved `User` row, the matching `ExternalIdentity` row, and the verified
`(issuer, subject)`. `PreAuthIdentity` carries the verified `(issuer, subject)` and nothing
else — no user row, no identity row, no provider. `RequestContext` carries the identity
variant, the `RouteMetadata` record, the `ClientIpBucketKind`, one `evaluated_at`, and one
`attempt_id`. Every dataclass is `frozen=True, slots=True`. Add a module docstring recording
that the stored `ExternalIdentity.provider` column is the sole per-request classifier and that
`User.registered_at` is reporting-only and must never be used as a competing classifier.
`ClientIpBucketKind` records the bucket kind only — `ipv4`, `ipv6`, or `unresolved` — and the
context carries no client address, because §9 is deferred so `xff_num_trusted_hops` is unpinned
and a stored address would be trusted rather than proven. It is never recomputed from raw
forwarded headers.

Add `get_request_context`, `get_linked_identity`, and `get_preauth_identity` to
`src/nativespeaker/api/app/dependencies.py`. Each reads `REQUEST_CONTEXT_SCOPE_KEY` off

`auth_required` — that is §1.4's "fails loudly", and putting the check in one place stops each
of the seven later phases re-implementing it. `get_linked_identity` additionally raises when
the attached variant is pre-auth; `get_preauth_identity` raises when it is linked. Keep
`get_config`, `get_db`, and `get_chat_service` verbatim.

Add `context.py` exports to the `auth/__init__.py` barrel, keeping the `__all__`-first
alphabetized shape.
