<objective>
Repair the model layer against the applied v2.0 schema so real queries work, and remove the
subscription-plan configuration that the schema replaced with `core.access_tiers`.

Purpose: D-14's "the application boots" is *query* repair, not import repair — `import
nativespeaker.api.app.main` already succeeds and the lifespan already runs, but `select(User)`
fails with `UndefinedColumnError: column users.jwt_sub` and `select(UsageMonthly)` fails with
`UndefinedTableError`. This plan closes that gap so plan 05's identity resolution has a model
layer it can query.

Output: a seven-column `User`, no subscription-plan machinery anywhere, and a live-database
test that proves it.
</objective>
