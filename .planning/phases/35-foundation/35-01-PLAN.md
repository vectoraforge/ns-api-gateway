Create `src/nativespeaker/api/auth/wire.py` implementing §1.1 against the raw ASGI header
list. `extract_bearer(raw_headers)` counts every `(k, v)` whose key equals the byte string
`b"authorization"` — ASGI guarantees lowercase keys, so a differently-cased field arrives
already folded into that same key and counts as a duplicate. Zero values returns
`BoundedReason.missing_token`; two or more returns `BoundedReason.duplicate_authorization`
without inspecting either value; a single value containing a comma, CR, or LF returns
`duplicate_authorization`; a value that does not split into exactly two space-separated parts,
or whose first part is not `bearer` case-insensitively, or whose second part is empty, returns
`BoundedReason.malformed`. On success it returns the token bytes decoded as strict ASCII with
no trimming, case-folding, or re-encoding. Never reach for `Headers.get`, `Headers[...]`, or
FastAPI's `Header()` alias anywhere in this module: `Headers.get` returns only the first value
and would silently satisfy the duplicate-field attack this contract exists to reject.

Create `src/nativespeaker/api/auth/barrier.py` as a pure-ASGI middleware class — a
three-argument callable, not a `BaseHTTPMiddleware` subclass. `__init__` stores only
`self.app` and captures nothing from `app.state`: the middleware is constructed at
`add_middleware` time, before the lifespan runs, and the e2e rollback fixture works by
swapping `app.state.session_factory` afterwards, so any attribute cached in `__init__` writes
to the real database and never rolls back. `__call__` passes non-`http` scopes straight
through. For an `http` scope it resolves the matched route by iterating
`scope["app"].router.routes` and calling `route.matches(scope)`, taking the first
`starlette.routing.Match.FULL`. Starlette never sets `scope["route"]` on the way in — FastAPI
writes it inside `APIRoute.matches` during router dispatch, which happens after the barrier has
already had to decide — so asking the router directly is the only way the barrier and the
router can never disagree. When nothing matches `FULL`, including a `Match.PARTIAL`
wrong-method request, pass through: §4.1 places route/method mismatch in the admission phase,
so the router keeps its own 404 and its own 405 and no audit row is written. When the matched
route's registry category is not `authenticated`, pass through. Otherwise apply
`extract_bearer(scope["headers"])`; on any bounded reason, build `error_response(AUTH_REQUIRED)`
and await it against `(scope, receive, send)` without ever calling `self.app`. Return the
response — never raise it: `add_middleware` places user middleware outside Starlette's
`ExceptionMiddleware`, so `app.add_exception_handler` never sees a middleware exception and a
raised registry error would surface as a 500. A verified token still reaching this point passes
through unchanged in this plan; plan 06 adds verification, identity resolution, and the typed
context on this same seam.
