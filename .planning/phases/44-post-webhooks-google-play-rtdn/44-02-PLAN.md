    `#GOOGLE_PLAY_PUSH_AUDIENCE=https://api.example.com/webhooks/google-play/rtdn`,
    `#GOOGLE_PLAY_PUSH_SERVICE_ACCOUNT_EMAIL=rtdn-push@example.iam.gserviceaccount.com`.

    State, in prose, five operational facts a deployer cannot learn anywhere else:

    1. Where each value is read: the package name from Play Console; the audience and the service
       account from the Pub/Sub push subscription's Authentication settings, where the audience must
       be the exact `aud` string the push token will carry.
    2. That none of the three is a secret, and that the route uses Application Default
       Credentials — the same identity Firebase Admin already runs on — so this phase adds no key
       file and no new secret. The `androidpublisher` grant is made in Play Console, not in GCP IAM.
    3. That while any of the three is absent, or while ADC is absent, the route is still registered
       and answers `verification_temporarily_unavailable`, and one named warning is written at boot.
    4. **What a wrong audience costs.** Cloud Pub/Sub acknowledges only 102, 200, 201, 202 and 204
       and resends on every other status, including 401. A mistyped audience therefore turns every
       genuine notification into a refusal that Pub/Sub retries until message retention expires, and
       nothing about the deployment looks broken from the outside. The `stage` field on the
       refusal log line is the only thing that separates "this deployment is misconfigured" from
       "this token is not Google's".
    5. That the Android client must pass this project's server-minted
       `store_purchase_tokens.identity_value` as `BillingFlowParams` `obfuscatedAccountId` at
       purchase time. Google does not mint that value. Without it every Google subscription ingests
       unattributed and grants nobody anything — the path degrades quietly rather than failing.

    Name both egress hosts the pod must reach: `https://www.googleapis.com` for the JWKS document,
    which Firebase already requires, and `https://androidpublisher.googleapis.com`, which this
    application has never called before.
